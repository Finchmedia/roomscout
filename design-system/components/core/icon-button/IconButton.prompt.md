Circular icon button for compact controls.

```jsx
<IconButton label="Suche pausieren"><Icon name="pause" size={16} /></IconButton>
<IconButton variant="accent" size={46} label="Mit Scout sprechen"><Icon name="mic" size={18} /></IconButton>
<IconButton variant="subtle" size={44} label="Senden"><Icon name="send" size={18} /></IconButton>
```

- `outline` = 1px warm border on rgba white .04 (header); `accent` = orange (the voice entry inside composers).
