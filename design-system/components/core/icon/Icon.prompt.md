The RoomScout icon set as one component; use it for every glyph instead of hand-drawing SVGs.

```jsx
<Icon name="mic" size={20} />
<Icon name="check" size={18} color="var(--rs-orange)" />
```

- Facts: `pin` (Ort), `users` (Band), `clock` (Zeit), `drum` (Ausstattung); budget uses a plain "€" glyph.
- Checkmarks in offers are orange (`--rs-orange`, stroke 2.2).
- `ICON_NAMES` export lists every name.
